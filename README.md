# Majbur Bot

Guruhga va kanalga istagancha odam yig'ishda yordam beradigan Telegram bot.

## Imkoniyatlari

1. Guruhga odam yig'ish — /guruh 5 dan keyin, guruh a'zolari 5 ta odam qo'shmaguncha yoza olishmaydi.
2. Kanalga odam yig'ish — /kanal @kanal_nomi dan keyin, guruh a'zolari kanalga a'zo bo'lmaguncha yoza olishmaydi.

## Buyruqlar

- /start
- /help
- /guruh <son>
- /kanal <@username yoki off>

## Muhim

Bot guruhda to'liq ADMIN bo'lishi, "Restrict members" huquqiga ega bo'lishi shart.
Kanal talabi uchun botni kanalga ham ADMIN qilib qo'shish kerak.
